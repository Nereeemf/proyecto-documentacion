\# Glosario de desarrollo web



\- \*\*Frontend:\*\* parte visual de una página web.

\- \*\*Backend:\*\* parte interna de una aplicación.

\- \*\*HTML:\*\* lenguaje que define la estructura de una página.

\- \*\*CSS:\*\* lenguaje que define el diseño.

\- \*\*JavaScript:\*\* lenguaje de programación que añade interactividad.

\- \*\*Servidor:\*\* sistema que proporciona información a los usuarios.

\- \*\*Base de datos:\*\* sistema que almacena información.

\- \*\*API:\*\* conjunto de reglas que permite comunicar aplicaciones.

\- \*\*Framework:\*\* conjunto de herramientas que facilita el desarrollo.

\- \*\*HTTPS:\*\* protocolo seguro para transmitir información por Internet.
