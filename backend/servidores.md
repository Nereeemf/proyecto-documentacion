\# Servidores web



\## ¿Qué es un servidor web?



Un servidor web es un sistema que almacena y proporciona páginas y contenidos a los usuarios cuando acceden a una página web.



\## Funcionamiento



Cuando un usuario entra en una página web:



1\. El navegador envía una petición.

2\. El servidor recibe la petición.

3\. El servidor procesa la solicitud.

4\. El servidor devuelve una respuesta al navegador.



\## Tipos de servidores



\- \*\*Apache:\*\* servidor web muy utilizado.

\- \*\*Nginx:\*\* servidor conocido por su rendimiento.

\- \*\*Microsoft IIS:\*\* servidor web desarrollado por Microsoft.



\## Importancia



Los servidores permiten que las páginas y aplicaciones web estén disponibles para los usuarios.
