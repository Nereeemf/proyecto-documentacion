# Bases de datos



## ¿Qué es una base de datos?



Una base de datos es un sistema que permite almacenar, organizar y consultar información.



## Tipos de bases de datos



- **Relacionales:** organizan la información en tablas. Ejemplo: MySQL.

- **No relacionales:** almacenan información de diferentes formas. Ejemplo: MongoDB.



## Sistemas de gestión de bases de datos



- MySQL.

- PostgreSQL.

- Oracle.

- MongoDB.



## Importancia



Las bases de datos permiten guardar y gestionar información de usuarios, productos, pedidos y otros datos de las aplicaciones web.
