\# APIs REST



\## ¿Qué es una API?



Una API es un conjunto de reglas que permite que diferentes aplicaciones se comuniquen entre sí.



\## ¿Qué es REST?



REST es un estilo de arquitectura que permite intercambiar información entre aplicaciones mediante peticiones HTTP.



\## Métodos HTTP principales



\- \*\*GET:\*\* obtener información.

\- \*\*POST:\*\* enviar o crear información.

\- \*\*PUT:\*\* actualizar información.

\- \*\*DELETE:\*\* eliminar información.



\## Formato de datos



Las APIs REST suelen utilizar JSON para enviar y recibir información.



\## Importancia



Las APIs REST permiten conectar aplicaciones, servicios y bases de datos de forma organizada.
