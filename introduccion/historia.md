\# Historia del desarrollo web



\## Orígenes



El desarrollo web comenzó en 1989, cuando Tim Berners-Lee propuso la World Wide Web.



En sus inicios, las páginas web eran muy sencillas y solo contenían texto y enlaces.



\## Evolución



\- \*\*Años 90:\*\* aparecieron las primeras páginas web y se empezó a utilizar HTML.

\- \*\*Años 2000:\*\* las páginas web comenzaron a ser más dinámicas e interactivas.

\- \*\*Años 2010:\*\* aumentó el uso de móviles y diseños adaptables.

\- \*\*Actualidad:\*\* existen aplicaciones web avanzadas y tecnologías modernas.



\## Situación actual



Hoy en día, el desarrollo web permite crear tiendas online, redes sociales, plataformas educativas y muchos otros servicios.
