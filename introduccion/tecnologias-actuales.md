# Tecnologías actuales del desarrollo web



## HTML



HTML es el lenguaje que se utiliza para crear la estructura y el contenido de una página web.



## CSS



CSS permite dar estilo a las páginas web, modificando colores, tamaños, fuentes y distribución.



## JavaScript



JavaScript permite añadir interactividad y funciones dinámicas a las páginas web.



## Frameworks y herramientas



Algunas herramientas utilizadas actualmente son:



- React: biblioteca de JavaScript para crear interfaces.

- Angular: framework para desarrollar aplicaciones web.

- Node.js: entorno que permite ejecutar JavaScript en el servidor.



## Importancia



Estas tecnologías permiten crear páginas web modernas, rápidas, atractivas y adaptadas a diferentes dispositivos.
