\# JavaScript moderno



\## ¿Qué es JavaScript?



JavaScript es un lenguaje de programación que permite añadir interactividad y dinamismo a las páginas web.



\## Características principales



\- Permite responder a las acciones de los usuarios.

\- Puede modificar el contenido de una página.

\- Permite validar formularios.

\- Facilita la creación de aplicaciones interactivas.



\## Funciones y variables



JavaScript utiliza variables para almacenar información y funciones para ejecutar diferentes tareas.



\## Uso actual



Se utiliza tanto en el frontend como en el backend mediante herramientas como Node.js.



\## Importancia



JavaScript es uno de los lenguajes más importantes del desarrollo web porque permite crear experiencias interactivas.
