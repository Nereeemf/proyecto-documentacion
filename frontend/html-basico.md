# HTML básico



## ¿Qué es HTML?



HTML es un lenguaje de marcado que se utiliza para crear la estructura de las páginas web.



## Elementos principales



- `<html>`: elemento principal de una página.

- `<head>`: contiene información sobre la página.

- `<title>`: establece el título de la página.

- `<body>`: contiene el contenido visible.

- `<h1>`: crea un encabezado.

- `<p>`: permite escribir párrafos.

- `<a>`: crea enlaces.

- `<img>`: permite insertar imágenes.



## Ejemplo de HTML



Una página básica puede contener un título, varios párrafos e imágenes.



## Importancia



HTML es fundamental en el desarrollo web porque permite organizar el contenido de cualquier página.

## Formularios HTML

HTML permite crear formularios para recoger información de los usuarios.

Se pueden utilizar elementos como input, button y form para crear formularios interactivos.
