\# CSS avanzado



\## ¿Qué es CSS?



CSS es un lenguaje que permite definir el diseño y la apariencia de las páginas web.



\## Propiedades principales



\- `color`: cambia el color del texto.

\- `background-color`: cambia el color de fondo.

\- `font-size`: modifica el tamaño de la letra.

\- `margin`: establece el espacio exterior.

\- `padding`: establece el espacio interior.

\- `border`: añade bordes a los elementos.



\## Diseño avanzado



CSS permite utilizar herramientas como Flexbox y Grid para organizar los elementos de una página.



También permite crear diseños adaptables a móviles, tabletas y ordenadores.



\## Importancia



CSS es fundamental para conseguir páginas web atractivas, ordenadas y fáciles de utilizar.
